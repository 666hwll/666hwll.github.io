Schematic Editor

  • Z - Ground
  • O - Port (for Sheets)
  • L - Label
  • U - Power-Port
  • R / W - Wire
  • ⇧ Shift + C - End Selection
  • ⇥ Tab - Pause Editor (for Panel)

  • Ctrl + 🖱 Right Click - Zoom
    • 🖱 Scroll Up - Zoom in
    • 🖱 Scroll Down - Zoom out

PCB Editor

  • L - Line, not Trace!
  • W - Wire/Trace
  • D - Differential Pair Routing
  • + / Num + - Layer up
  • - / Num − - Layer down

Global

  • Ctrl + 🖱 Double Left Click - Follow Trace
  • "Find Similar Object" - custom selection filter
